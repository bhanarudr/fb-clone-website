# fb-clone-website

This project is a **Facebook website clone** that I created while learning and practicing **Git and GitHub** through a Git tutorial.

The main purpose of this project was to understand how Git works in a real development project, including creating repositories, tracking changes, making commits, and managing project files.

## About the Project

This website is inspired by the design and layout of Facebook. It was created as a learning project to practice web development concepts while simultaneously getting familiar with version control using Git.

## What I Learned

While working on this project, I practiced:

* Using Git for version control
* Creating and managing a Git repository
* Making commits and tracking changes
* Understanding Git's basic workflow
* Connecting a local project to GitHub
* Organizing files in a web development project
* Building a website inspired by an existing platform

## Purpose

This is an **educational project** and was created for learning purposes. It is not affiliated with or endorsed by Facebook/Meta.

I plan to continue improving my web development and Git skills by building more projects and exploring modern technologies.
